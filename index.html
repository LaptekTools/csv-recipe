LAPTEKTOOLS · LOCAL PROTOTYPE

Repeat the same CSV export.

Choose columns, rename them and save the order for next time. Files stay in this browser tab. No account or server upload.

1. Choose your exported CSV

Up to 10 MiB, 50,000 data rows and 120 columns. Quoted commas and multiline text are supported. No guessing of missing columns.

2. Set the columns

Select columns, edit the exported heading and use the arrows to set their order.

Choose a CSV to begin.

3. Preview before downloading

Original-string mode preserves formula-like values. A spreadsheet may execute them when opened. Neither mode changes the source file.
